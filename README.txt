IMPORTANT STATIC RSVP NOTE
--------------------------
A pure static HTML website cannot store RSVP submissions by itself.
For the live couple websites, connect the RSVP section to one of these:
- Google Forms
- Formspree
- FormSubmit
- GoHighLevel form
- another form backend you control

The demo currently saves the RSVP only in the visitor's browser (localStorage) so the interaction can be previewed without a backend.

BEFORE PUBLISHING THE AHAVACO SALES SITE
----------------------------------------
1. Replace: https://m.me/YOUR_PAGE_USERNAME
2. Add your real Facebook / Instagram links if desired.
3. Decide the exact lifetime-hosting policy and keep the wording consistent with what you can support.
4. If you offer custom domains, list that as a separate optional cost because domains normally renew yearly.
